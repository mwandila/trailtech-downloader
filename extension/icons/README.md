# Extension Icons

Place your extension icons here with the following filenames:
- `icon16.png` - 16x16 pixels (toolbar)
- `icon32.png` - 32x32 pixels (toolbar retina)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Icon Generation

You can use an online tool like:
- https://realfavicongenerator.net/
- https://www.favicon-generator.org/

Or create a simple colored square as a placeholder:
- Use any image editor (Paint, Photoshop, GIMP, etc.)
- Create a square with a download arrow icon
- Export in required sizes
